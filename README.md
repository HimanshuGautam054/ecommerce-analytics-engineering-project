# Ecommerce Analytics Engineering Project

## Project Overview

This project builds an end-to-end ecommerce analytics pipeline using DBT, Google BigQuery, SQL, and Looker Studio.

The main objective of this project is to transform raw ecommerce transactional data into clean, business-ready analytical models and create interactive dashboards for executive revenue tracking and customer retention analysis.

This project demonstrates practical skills in:

- Data Engineering
- Data Modeling
- SQL Transformations
- DBT Development
- BigQuery Analytics
- Dashboard Development
- Business KPI Reporting
- Git & GitHub Version Control

---

## Tech Stack

- Google BigQuery
- DBT (Data Build Tool)
- SQL
- Looker Studio
- Git & GitHub
- VS Code

---

## Project Architecture

Raw Data → Staging Models → Business Models → Final Reporting Layer → Looker Studio Dashboards

### Workflow

1. Raw ecommerce data loaded into BigQuery
2. DBT staging models created for data cleaning
3. Intermediate business models built for revenue and retention analysis
4. Final analytical models prepared for reporting
5. Interactive dashboards built in Looker Studio
6. Full project version-controlled using GitHub
